Refactored C++11 Cryptographic Framework

Visual Cryptography Split & Reconstruction

An academic research prototype transformed into a highly optimized, production-grade cryptographic playground. Split secrets into noise, stack to decrypt.

Naor-Shamir VCS

Features perfect information-theoretic security. Converts each secret pixel into a 2×1 subpixel pair, causing horizontal size expansion.

Random Grid (RG)

Maintains space efficiency with zero pixel expansion. Achieves perfect security while matching the exact dimensions of the secret image.

Meaningful Cover (DHCOD)

Hides shares inside custom grayscale cover images using 4×4 Bayer ordered dithering. Decrypts with perfect resolution via digital XOR.
